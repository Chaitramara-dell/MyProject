# 🩺 Troubleshooting

Common issues and solutions during installation or setup.

| Issue | Cause | Solution |
|-------|--------|-----------|
| `npm not recognized` | Node.js not installed | Install Node.js and restart terminal |
| `Port already in use` | Another app using port 3000 | Change port in `.env` file |
| `Permission denied` | Missing admin rights | Run terminal as Administrator |
| `Page not loading` | Server not running | Run `npm start` |

> 🆘 **Still stuck?** Try deleting `node_modules` and re-running `npm install`.
