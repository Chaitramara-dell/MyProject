# ❓ Frequently Asked Questions

### Q1. Can I use this app on macOS or Linux?
Yes! It works on Windows, macOS, and Linux.

### Q2. How do I reset configuration?
Delete `.env` and re-run the setup commands.

### Q3. How do I stop the app?
Press **Ctrl + C** in the terminal.

### Q4. Where can I report bugs?
Raise an issue on GitHub → `Issues` tab in your repository.
